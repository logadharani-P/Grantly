# 🎓 GRANTLY – Scholarship Discovery & Application Assistant

**Discover opportunities. Unlock your potential. Build your future.**

GRANTLY is a scholarship discovery and application assistance platform designed to help school students, undergraduate students, and postgraduate students find scholarship opportunities that match their academic background, eligibility, and interests.

Our goal is to make scholarship discovery easier, more accessible, and more organized through personalized recommendations and AI-assisted guidance.

## ✨ Key Features

- **Personalized Scholarship Discovery** – Find relevant scholarships based on your academic profile and eligibility.
- **Smart Search & Filters** – Explore scholarships by education level, category, location, and other criteria.
- **AI Scholarship Assistant** – Get guidance and answers to scholarship-related questions.
- **Student Dashboard** – Track scholarship deadlines, saved opportunities, and application progress.
- **Application Tracker** – Organize and monitor your scholarship applications.
- **Profile Management** – Maintain your academic details and scholarship preferences.
- **Education News** – Stay informed about scholarship announcements and educational opportunities.
- **Responsive Design** – Access the platform across desktop, tablet, and mobile devices.
- **Dark Mode** – Switch between light and dark themes.

## 🚀 Getting Started

Follow these steps to run GRANTLY locally.

### Prerequisites

- Node.js (LTS version recommended)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/logadharani-P/Grantly.git
```

**2. Navigate to the project directory**

```bash
cd Grantly
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

To check and build the application:

```bash
npm run build
```

## 📁 Project Goals

GRANTLY aims to:

- Make scholarship information easier to discover.
- Help students understand scholarship eligibility.
- Reduce confusion during scholarship preparation.
- Keep application information organized.
- Make educational opportunities more accessible.

## 🔒 Data & Privacy

GRANTLY is designed with student privacy in mind. Personal and academic information should be handled responsibly. Never commit API keys, passwords, private credentials, or `.env` files to the repository.
